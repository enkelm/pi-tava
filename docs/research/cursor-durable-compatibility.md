# Cursor SDK / Durable compatibility

Research snapshot: 2026-10-11. **Defer full Cursor integration beyond milestone 1; do LiteLLM first.** Native registration is feasible, but the installed Cursor provider is not a standalone transport and its safety/restart guarantees do not carry into Coop.

Source aliases: `C = ~/.pi/agent/npm/node_modules/pi-cursor-sdk`, `S = ~/.pi/agent/npm/node_modules/@cursor/sdk`, `D = node_modules/@earendil-works/pi-durable`. Only installed source and public docs were inspected—not credentials or secret configuration. No SDK execution/login/inference, tests, installs, code edits or restart. Only this note was written; unrelated changes were preserved.

## Versions and exports: feasible on this machine

- Installed **pi-cursor-sdk 0.5.3 requires Node >=24**, pins **@cursor/sdk 1.0.37**; SDK itself requires **>=22.13**. Coop declares **>=22.19**. Read-only `node -p` reported **v24.20.0** at `~/.nvm/versions/node/v24.20.0/bin/node`; the process list also showed that executable. Thus this host meets both floors, but reusing the extension on all Coop-supported Node versions is unsupported. SDK execution/platform compatibility was not tested. [C/package.json:3,119–121,163–169; S/package.json:3,11–13; package.json:20–22; official [runtime support](https://cursor.com/docs/sdk/typescript#runtime-support)].
- C declares Pi entrypoint `dist/index.js`, **no package-root exports/main/types API and no standalone native Provider factory**. Its internal `registerCursorProviderBinding(pi)` constructs a native Provider through a Pi-owned lifecycle closure. Internal `streamCursor` requires scope, request provenance, usage recorder and lifecycle ownership. This is not a supported importable factory contract. [C/package.json, complete manifest, especially 198–202; C/src/index.ts:22–60,88–93; C/src/cursor-provider-binding.ts:27–112; C/src/cursor-provider.ts:54–73].
- Coop can register native Providers: ModelRuntime exposes `registerNativeProvider` / `unregisterProvider`; `configureModels` supplies the shared runtime to the harness. **Registration alone is a false positive:** Cursor streaming requires a one-use real-headers receipt captured by Pi's `before_provider_headers` event, including session projection and usage ownership. It explicitly rejects bare ModelRuntime streams. Durable directly calls `runtime.models.streamSimple`, not an owning Pi AgentSession. [node_modules/@earendil-works/pi-coding-agent/dist/core/model-runtime.d.ts:98–118; src/server/app.ts:257–259,305–309; C/src/cursor-provider-binding.ts:36–75; D/dist/harness/generation.js.map, embedded `../../src/harness/generation.ts`:401–410].

## Unsafe default: nested tools bypass Coop's boundary

Cursor LOCAL runs its agent loop **inside Node**, with hosted inference. Native shell/edit/MCP/delegates remain Cursor-owned; Pi tool toggles do not disable them. Default headless SDK calls execute without human approval; extension safety controls are off by default. Coop's Lancet hook protects **Durable ToolTask** calls, not arbitrary SDK execution. Native replay cards are display-only, not approval or replay-safe intents. **Enabling this default surface in Coop would bypass its safety policy.** [C/README.md:307–322,541–556; src/server/extensions/guard.ts:17–75; official [overview](https://cursor.com/docs/sdk/typescript#overview) and [quickstart warning](https://cursor.com/docs/sdk/typescript#quick-start)].

The Pi bridge deliberately emits a normal toolCall and awaits its actual toolResult rather than invoking handlers directly. A Durable equivalent is **plausible but unproved**. SDK customTools are not a shortcut: callbacks skip SDK interactive approval and expose optional toolCallId/sessionId, **no abort signal/deadline**. Direct handler calls lose Durable intent, guard, replay and attribution. Delegates can have their own unrestricted toolsets unless separately constrained. [C/README.md:549–556; S/dist/esm/options.d.ts:55–64,86–109,187–196,398–407; official [custom tools](https://cursor.com/docs/sdk/typescript#custom-tools)].

## Restart, cancellation and cleanup: blockers remain

- **Restart:** Durable's request checkpoint supports resend after recovery; safe/unsafe replay protects actual ToolTasks. Cursor may already have changed files inside that request. Pi resume uses branch/session/store/model identities and explicitly rejects crash-ambiguous trailing input; these are Pi JSONL semantics, not Durable recovery. SDK idempotencyKey fields do not establish exactly-once local recovery; the extension's send supplies no key. [D/dist/harness/generation.d.ts:15–24; D/README.md:168; C/README.md:324–336; C/src/cursor-provider-turn-send.ts:98–126; S/dist/esm/agent.d.ts:33–62].
- **Stop:** abort requests bridge/Run cancellation, but finalization awaits SDK settlement. Public Run has cancel/wait but no caller deadline. Extension documentation warns nonsettling controllers can leave cancellation waiting. A timeout is not proof child work stopped. [C/src/cursor-provider-turn-send.ts:50–71,151–155; C/src/cursor-provider-turn-finalize.ts:153–165; S/dist/esm/run.d.ts:63–82; C/README.md:521].
- **Cleanup/attribution:** Pi shutdown/compact/tree/model events manage pooled agents, stores and branch-owned usage journals. Coop shutdown closes the harness for later resume, not Pi session_shutdown. A safe adapter needs explicit conversation/requester ownership and durable run/cleanup receipts; no fake session manager or generalized ExtensionAPI shim. [C/src/cursor-session-agent-lifecycle.ts:17–60; C/src/cursor-usage-ledger.ts:283–328,493–499; src/server/app.ts:1697–1734; docs/architecture.md, “Who Pi works for”].

## Usage: zero estimates do not mean free

Discovered catalog rates are **zero**; message cost uses configured Pi pricing and context-occupancy tokens/estimates, not cumulative inner-loop billing. Public getUsage returns eventually consistent provider charge observations; optional cost can be absent, local billing IDs are usage UUIDs rather than client run IDs, and account access may be unavailable. Observed charged zero can mean plan-included/BYOK/credit usage. Keep estimates, raw token facts and revised provider charges separate; unknown is not zero, no proven quota or final-invoice reconciliation. [C/src/model-discovery.ts:25,255; C/src/cursor-usage-accounting.ts:89–124,129–167; C/README.md:517–539,656; S/dist/esm/usage-types.d.ts:1–39; official [Agent.getUsage](https://cursor.com/docs/sdk/typescript#agentgetusage)].

**Limited feasible candidate, not validated support:** public SDK LOCAL text-only execution with `tools: []`, no ambient settings/MCP/delegates, isolated stores and explicit disposal—the extension already does this for summaries. It is not a full coding provider; cancellation, recovery and billing still require qualification. Full adapter design is deferred. [C/src/cursor-provider-turn-summary.ts:28–100; S/dist/esm/options.d.ts:382–410].
