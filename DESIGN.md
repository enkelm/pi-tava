# pi-tava visual identity

## Scope

This is the first branding pass, not a replacement of the app's information architecture. Keep existing conversation, project, Work Item, terminal and settings interactions. Tava is the built-in default for new browsers, with its paired Dark and Light assignments and System color mode. Keep existing personal appearance choices and owner-selected defaults; never overwrite them to apply it.

## Artwork

The owner supplied the Tava pot-shaped Pi artwork. Use the orange-backed version for the favicon and installed-app icons. Use the background-free SVG for interface marks, tinted with the surrounding brand color so it remains visible with light, dark and custom palettes. Do not replace named agents' avatars, people's avatars, or Pi symbols in user-authored content.

Assets live under `web/pi-tava-*`. The maskable and Apple touch icons have an opaque orange ground; the regular favicon and PNG icons retain the supplied transparent corners. Keep essential artwork inside the maskable safe zone.

## Colors

- Artwork orange: `#FF692A`, with the supplied icon's deeper orange `#E83D14`.
- Dark-mode accent: a restrained orange `#E98A58`; large primary controls use a 40% orange tonal fill with cream text rather than solid orange.
- Cream: `#FFF7E8`, taken directly from the supplied mark.
- Dark working ground: `#241B17`, with darker brown navigation and code surfaces.
- Light working ground: cream, with brown text and a deeper `#B93912` accent for readable small controls.

Orange is for wayfinding, focus, primary actions and brand marks—not a full-screen fill behind conversations. Keep success, warning and failure colors distinct. Body text and actionable accent text must reach 4.5:1 against the theme's working surfaces.

## Form and type

Use the existing layout and density controls. Tava adds modest rounded controls and windows, solid focus borders and quiet tonal selection. Preserve the user's font choice, code/terminal fonts, text size, widths, reduced-motion preference and touch target sizes. Do not introduce motion as part of this branding pass.

## Naming and compatibility

The display name, package and primary command are `pi-tava`. The `pi-coop` command remains an alias. Retain real upstream Pi Pocket attribution and repository links, and compatibility-critical data paths, environment variables, stored IDs and APIs. Historical research and provenance remain historical evidence rather than being rewritten as if the new brand always existed.
